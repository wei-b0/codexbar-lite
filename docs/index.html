Private by design

Your Codex login is enough.

Usage trackers often ask you to hand over access to sensitive parts of your Mac just to display a number. CodexBar Lite reads the same local session codex login already created, and makes the minimum request needed to show your usage — directly from chatgpt.com.

There is no third-party backend, account, telemetry, or analytics. The app stores only preferences and a local usage cache.

  • No Chrome or browser-profile access
  • No browser cookies
  • No macOS Keychain
  • No Accessibility permission
  • No Screen Recording permission
  • No Full Disk Access
  • No API key
  • No third-party account

FAQ

Questions, answered.

Does CodexBar Lite need my Keychain, Chrome, or an API key?

No. It reads ~/.codex/auth.json, the session your existing codex login already created, and requests usage directly from chatgpt.com. Nothing else on your Mac is touched.

Does my data leave my Mac?

Only the minimum request needed to show your usage goes to chatgpt.com. There is no third-party backend, account, telemetry, or analytics.

What if I haven't run codex login yet?

Open the app. If no Codex session exists, it launches codex login in Terminal and watches for completion — usage appears automatically once login succeeds.

How do I uninstall it?

Quit CodexBar Lite and move it from /Applications to Trash. Optional cleanup: rm -rf ~/Library/Application\ Support/CodexBarLite and defaults delete dev.vaibhav.codexbar.

Is this affiliated with OpenAI?

No. CodexBar Lite is an independent utility and is not affiliated with, endorsed by, or sponsored by OpenAI.
